# Rate Diary – Supplier Rate Tracker (simple)

Ek seedhi table: **Date | Item | Qty | Rate (1 pc) | Remark**

- Item, qty, rate aur date likh kar "Jodo" dabao.
- Wahi item dobara likhoge to **Remark** apne aap banega, jaise
  `₹5 badh gaye (pehle ₹250 · 10-05-2026)` ya `₹0.5 kam hue`.
- Likhte waqt hi pichhla rate dikh jata hai.
- Item dhundo, entry delete karo, Excel (CSV) download karo.

`rate-diary.html` asli page hai (Claude link par data online save hota hai).
`index.html` seedha browser mein khulta hai – usme data sirf usi browser mein save hota hai.
