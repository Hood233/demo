# Rate Diary – Supplier Rate Tracker

Supplier jo rate list bhejta hai, use yahan save karo. 3-4 mahine baad nayi list aaye to har item ke saath dikhega:
- pichhla rate kya tha
- kis supplier ne diya tha
- kitna badha ya ghata (▲/▼ %)

## Kaise chalega
- **Claude link par (AI ke saath):** WhatsApp message ya rate list ki photo daalo, AI items aur rate nikaal dega. Data online save hota hai.
- **Bina AI ke:** `index.html` browser mein kholo. Text wali list simple tareeke se padhi jayegi. Data sirf us browser mein save hoga.

## Sections
1. **Nayi rate list:** supplier aur tareekh chuno, rate list paste karo (ya photo daalo), "Items nikalo" dabao, check karke save karo.
2. **Purana rate dekho:** jo saamaan mangwana hai uski list daalo. Har item ka aakhri rate aur sabse sasta supplier dikhega. List copy karke supplier ko WhatsApp par bhej sakte ho.
3. **Saamaan:** har item ki poori rate history aur graph.
4. **Saari rate lists:** purani lists dekho, edit ya delete karo, aur sab kuch Excel (CSV) mein download karo.

`rate-diary.html` asli page hai. `index.html` usi ka seedha browser mein khulne wala roop hai.
