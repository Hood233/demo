# 🌿 Sehat Diary – Daily Health Tracker

Ek simple web app jisme aap apni roz ki sehat ka record rakh sakte ho. Isko install karne ki zaroorat nahi hai, aur ye phone aur computer dono par chalta hai.

## Chalane ka tareeka
`health-tracker/index.html` ko kisi bhi browser (Chrome, Edge, Safari) mein kholo. Bas itna hi karna hai.
Saara data aapke browser mein hi save hota hai (localStorage). Ye kisi server par nahi jaata.

## Features
- **👤 Profile**: naam, umar, male/female, lambai, wazan, activity, goal aur veg/non-veg. Isi ke hisaab se aapke target bante hain: calories, protein, paani aur vitamins.
- **🏠 Aaj**:
  - 💧 Paani: kitne glass piye aur kitne peene chahiye the
  - 🚶 Morning walk ki ya nahi, aur kitne minute
  - ✅ Exercise, dhoop, junk food, neend, wazan aur mood
  - 🍽️ Aaj kya khaya: 45+ Indian khane (roti, dal, paneer, anda, phal, junk…)
  - 🧪 Vitamin A, C, D, B12, Iron, Calcium, Protein aur Fiber mein se kitna mila aur **kya kam reh gaya**, saath mein kya khana chahiye
  - Roz ka **health score (0-100)**
- **📊 Record**: hafte (7 din) aur mahine (30 din) ka hisaab. Score aur paani ke chart, walk wale din, aur har din ki table.
- **🥗 Diet Plan**: BMI, aapki lifestyle kaisi honi chahiye, aur 7 din ka Indian diet plan (Veg / Veg + Anda / Non-Veg).
- **🚭 Nasha Mukti**: Daru, Cigarette aur Tambaku/Gutkha. Isme dikhta hai ki kitne din ho gaye, kitne paise bache aur body mein kya sudhaar hua. Dobara lene par reset ka button hai, aur sabse lamba streak bhi dikhta hai.
- **🩺 Jaanch**: BP, sugar (khali pet / khane ke baad), pulse aur wazan likho. Turant batata hai ki normal hai ya zyada, aur 30 din ka graph dikhata hai.
- **🔥 Streaks aur Badges**: kitne din se lagataar walk ki, paani poora piya ya record bhara. 12 badges jeet sakte ho.
- **💡 Report**: hafte/mahine ki automatic report – kaunsa vitamin sabse kam raha, junk food kitne din khaya, neend, wazan, BP aur dawai ka hisaab.
- **📅 Mahine ka calendar**: har din score ke hisaab se rang (laal/peela/hara).
- **💊 Dawai / Supplements**: apni dawai ki list banao aur roz tick karo.
- **🍲 Apna khana**: list mein nahi hai to khud calories aur vitamin daal kar jodo. "Jaldi jodo" buttons aur "Kal jaisa khana copy karo" bhi hai.
- **📲 Install / Offline**: website par kholne ke baad "Add to Home screen" karo, to app jaisa chalega aur internet ke bina bhi khulega.
- **💾 Backup**: JSON file mein download/restore.

> ⚠️ Ye app sirf jaankari ke liye hai, doctor ki salah ka vikalp nahi. Poshan ke aankde andaze (approx) hain.
