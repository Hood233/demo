# Dukaan Khata – dukaan ka poora hisaab

- **Khata (udhaar/jama):** Customer aur Supplier. "Aapne diye" / "Aapko mile", kitna lena–dena hai, poori entry list baaki ke saath, WhatsApp reminder aur hisaab bhejna, purana baaki.
- **Bill:** Sale aur Purchase bill – items, qty, rate, GST %, discount, kitna paisa mila/diya (Cash/UPI/Bank). Bill save karte hi party ka khata aur stock apne aap badalta hai. Bill WhatsApp par bhejo, edit ya delete karo (stock aur khata wapas ho jata hai).
- **Purchase rate remark:** purchase bill mein item likhte hi "Pichhla rate ₹250 → ₹5 badh gaye".
- **Saamaan / Stock:** bechne aur kharid ka rate, stock, kam stock alert, stock ki keemat, item ki kharid history.
- **Kharcha:** category ke hisaab se, mahine ka total.
- **Report:** aaj / mahina / pichhla mahina / saal (Apr–Mar) – bikri, kharid, kharcha, gross aur net munafa, GST bharna, top items, Excel (CSV) download.
- **Settings:** dukaan ka naam, phone, GSTIN, UPI; backup file aur restore.

`dukaan-khata.html` – Claude link wala page (data online). `index.html` – seedha browser mein (data usi browser mein).
`DukaanKhata.apk` – Android 7+ app (data phone mein). Build: `../android-app/README.md`.
